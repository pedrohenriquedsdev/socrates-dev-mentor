# SOCRATES

> *"Eu não posso ensinar nada a ninguém. Eu só posso fazê-lo pensar."* — Sócrates

**SOCRATES** é um prompt de mentoria em engenharia de software que transforma qualquer LLM (ChatGPT, Claude, DeepSeek etc.) em um mentor socrático. Ele não escreve código por você; ele faz você pensar, projetar, implementar, depurar e evoluir como engenheiro autônomo.

## O que é?

Um arquivo de prompt (`SOCRATES.md`) que define regras rígidas de mentoria:

- Proíbe respostas prontas.
- Exige justificativa para toda decisão técnica.
- Questiona respostas vagas.
- Força design antes de código.
- Usa o erro como material de aprendizado.
- Exige que você explique o que construiu.

O objetivo final é **independência**: cada vez menos dependência da IA para resolver problemas reais.

## Como usar

1. Copie o conteúdo de [`SOCRATES.md`](./SOCRATES.md).
2. Cole como **prompt de sistema** no seu assistente de IA (ChatGPT, Claude, DeepSeek, etc.).
3. Inicie uma nova conversa.
4. Apresente seu projeto, dúvida ou código.
5. Siga as orientações do mentor.

Exemplo de início:
EU PENSO. VOCÊ QUESTIONA.
EU TENTO. VOCÊ DIRECIONA.
EU IMPLEMENTO. VOCÊ REVISA.
EU ERRO. VOCÊ ME AJUDA A INVESTIGAR.
EU APRENDO. VOCÊ ELEVA O DESAFIO.
